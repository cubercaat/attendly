Himoya

Olti qatlam

1

Aylanuvchi QR

Har 3 soniyada yangi HMAC-imzolangan token, amal qilish muddati 9–12 soniya. Skrinshot yetib borguncha kod o'ladi.

2

GPS geofence

Auditoriya koordinatasidan belgilangan radius ichida. GPS aniqligi 100 m dan yomon bo'lsa qabul qilinmaydi; aniqlik masofadan chegiriladi, shunda adolatli bo'ladi.

3

Passkey (WebAuthn)

Telefonning o'z Face ID / Touch ID si. Qurilmaga bog'langan, nusxalab bo'lmaydi, server hech qanday biometrik ma'lumot ko'rmaydi.

4

Yuz tanish + liveness

Telefon yo'q bo'lsa zaxira yo'l: boshqa qurilmadan o'z yuzi bilan kiradi. Tasodifiy harakat so'raladi (to'g'ri qarang → chapga buring), shuning uchun rasm ko'rsatish o'tmaydi. Rasm saqlanmaydi — faqat 512 ta son.

5

Qurilma barmoq izi

Bitta telefondan ikki talaba belgilansa — yozuv bayroqlanadi va o'qituvchiga ko'rinadi.

6

O'qituvchi nazorati

Jonli ro'yxat, bir bosishda bekor qilish. Har bir urinish — muvaffaqiyatli yoki yo'q — sababi, IP si, masofasi bilan audit jurnaliga yoziladi.

Test rejimi

Telegram botisiz, parolsiz butun tizimni bosib ko'rish. GPS va biometrika baribir tekshiriladi — demo auditoriyani o'zingiz turgan nuqtaga ko'chirasiz.

cp .env.example .env     # DEMO_MODE=true
pip install -r requirements.txt
python seed_demo.py
uvicorn app.main:app --reload

# → http://localhost:8000/demo
Passkey va kamera HTTPS talab qiladi. Telefonda sinash uchun ngrok http 8000 va BASE_URL ni o'zgartiring.

Bu sahifa — loyihaning statik ko'rgazmasi. Haqiqiy tizim FastAPI va PostgreSQL da ishlaydi, shuning uchun u serverga joylashtiriladi; bu yerdagi QR va tekshiruvlar brauzerda simulyatsiya qilingan.
